# Entering Data Into The Bulk Import Spreadsheet
When working within the Bulk Import Spreadsheet, there are a few key guidelines to keep in mind:

**Top Container Type**

Each container in a collection must have a _Top Container Type_ (box, tube, volume, or oversize_folder) and a _Top Container Indicator_ (the container number). 

**Types of Containers**

There are four types of containers: _box_, _tube_, _oversized folder_, and _volume_. Some legacy collections may also include containers called _reel_ and _folder_. For more information on working with legacy collections, see the section of this manual on [Additions and Legacy Finding Aids](/Additions-to-Lecacy-Finding-Aids.md). 

**Electronic records** will be described as digital objects, which is an instance attached to an archival object. The desription and extent of the electronic records will be in the archival object, while the file name will be in the digital object.  

*Audio and moving image recordings** are described as subcontainers within a top container. All AMI data will be exported from SPEC and mapped to the Bulk Import Spreadsheet.


**Numbering Containers**

When processing various container types, the numbering scheme always restarts at 1. For example, after processing a box numbered 44 and moving onto items in tubes, the number of the tubes will begin again with 1. 

**Subcontainer Type**

If a box contains folders, it must include the _Subcontainer Type_ **_folder_** and the _Subcontainer Indicator_ (folder number).

If you are describing AMI, the _subcontainer type_ will always be **_item_**, and the _subcontainer indicator_ will be the AMI IDdentifier. You must also include the AMI recording's barcode in the subcontainer barcode field.

_Tube_, _volume_, and _oversized folder_ _Top Container Types_ will never have a _subcontainer type_.

**Dates**

A date that is also the folder title must be entered into the _dates_ field. Consecutive dates should be entered as a range, while dates with large gaps should be added to a separate date field of the same archival object. If you cannot determine a date, leave the field blank or use an estimated date with _circa_ as the prefix.

**Title Tags**

\<title> tags can be included in the spreadsheet when applicable.

**Subcontainer Indicators**

_Subcontainer indicators_ for the folders located inside boxes will typically be entered as a range. See the section of this documentation on [Archival Description ](/Archival_Description.md)for detailed information about working with and revising top containers in ASpace. See the example below for how to properly enter box ranges.

**Call Numbers and Unique Identifiers**

If the materials in your collection include a numbering or labeling system imposed by the creator or donor which may be helpful to the researcher, this unique identifier should be recorded in the _general notes_ field of each archival object. You should add the type of indentifer in the _label_ field. 

For more insight on data entry into ArchivesSpace, refer to the section of this manual on [Archival Description](../processing-manual/archival-description.md).
